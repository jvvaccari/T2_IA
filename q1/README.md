# Q1 - Jogo Quarto

## Estrutura

- `state.py`: estado do jogo, ações legais e regras de vitória.
- `minimax.py`: heurística e busca Minimax com poda alfa-beta.
- `mcts.py`: árvore Monte Carlo Tree Search.
- `cli.py`: tabuleiro, turno humano e partida interativa.
- `main.py`: ponto de entrada.

## Executar

Na raiz do projeto:

```powershell
python q1\main.py
```

Também é possível executar o pacote diretamente:

```powershell
python -m q1.main
```
